# Informe del CJC sobre propuestas para el PND

Proyecto LaTeX para editar en Overleaf. Contiene una versión abreviada de las diez propuestas sobre productividad, inteligencia artificial, investigación y financiación empresarial. Este informe propio del CJC conserva las diez propuestas. La selección de cinco para el documento de máximo tres páginas de la facultad se realiza por separado.

## Edición en Overleaf

1. Sincronizar este repositorio desde la integración GitHub del proyecto de Overleaf o importar su ZIP como un proyecto nuevo.
2. Seleccionar `main.tex` como documento principal y **pdfLaTeX** como compilador.
3. Compilar dos veces para actualizar las referencias. No se requiere BibTeX, archivos externos ni ejecución de scripts.

## Archivos

- `main.tex` reúne las partes del informe.
- `Paper/configuracion.tex` contiene formato, título, autoría, fecha y etiqueta de edición.
- `Paper/sections/Portada.tex` contiene la portada y la nota de uso de IA.
- `Paper/sections/ResumenEjecutivo.tex` contiene el resumen ejecutivo.
- `Paper/sections/Propuestas.tex` contiene las diez propuestas y los criterios de evaluación.
- `Paper/sections/Referencias.tex` contiene las fuentes enlazadas.
- `Paper/figures/logo_cjc_palatino_horizontal.png` es el logo utilizado por los informes anteriores.

La etiqueta «Propuestas para el PND» puede reemplazarse por un número de informe cuando se asigne. La fecha es fija y se modifica en `Paper/configuracion.tex`.

## Formato de referencia

Se reutilizaron el logo, la serie, la portada, el recuadro del resumen y los encabezados de los proyectos [Informe Actividades](https://github.com/oliverpardo1979/Informe_Actividades), [Informes departamentales](https://github.com/oliverpardo1979/Informes-departamentales), [Informe Tamaño](https://github.com/oliverpardo1979/Informe_Tamano) e [Informe Educación](https://github.com/oliverpardo1979/Informe_Educacion). Para esta versión breve se omite una página independiente de tabla de contenido. El texto se adaptó de las diez propuestas extensas preparadas por Oliver Pardo.

## Uso de inteligencia artificial

La portada identifica el uso de IA generativa en la búsqueda y síntesis de antecedentes, la redacción y la preparación de LaTeX. La nota no atribuye a la IA la responsabilidad por los argumentos o las propuestas.
